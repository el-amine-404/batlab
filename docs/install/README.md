# Installing a server

Follow in order. Each note is one step.

1. [Debian](./01-debian.md): install choices that matter later
2. [sudo](./02-sudo.md): only if the installer did not grant it
3. [SSH](./03-ssh.md): log in from your laptop with a key
4. [Static IP](./04-static-ip.md): a fixed address on the LAN
5. [Docker](./05-docker.md): engine, compose plugin, git, make
6. [batlab](./06-batlab.md): clone, secrets, first start
7. [Security](./07-security.md): SSH hardening, firewall, fail2ban, updates, ClamAV
